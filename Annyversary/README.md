# Aniversario — Maida y Cristian

Página del primer año juntos. Next.js, lista para Vercel.

## Local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Deploy en Vercel

1. Sube este repo a GitHub.
2. En [vercel.com](https://vercel.com) importa el proyecto (framework: Next.js).
3. Cada push a `main` vuelve a publicar el sitio.

Los textos de cada mes están en `lib/months.ts` (ahora lorem). Las fotos y videos viven en `public/NOMBRE_DEL_MES/` como `CUADRO` y `BACKGROUND`.
